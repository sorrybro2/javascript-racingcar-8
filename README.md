# javascript-racingcar-precourse


## 기능 요구사항

- [x] 각 시도마다 각 자동차별로 0~9 사이의 랜덤값을 생성한다.
- [x] 랜덤값이 4 이상이면 해당 자동차의 이동 거리를 1 증가시킨다.
- [] 시도 횟수만큼 라운드를 반복해서 이동 결과를 누적한다.
- [] 한 라운드가 끝날 때마다 현재까지의 진행 상황을 출력한다.
- [] 모든 라운드가 끝난 시점의 이동 거리를 비교한다.
- [] 최댓값을 가진 자동차(복수 가능)를 우승자로 선정한다.

## 입출력 요구사항

### 입력

- [] 각 자동차 이름은 5자 이하만 허용한다.
- [] 자동차 중복 이름이 들어오면 error 처리한다. 
- [] 시도 횟수는 자연수가 와야함
- [] 자동차 이름과 시도 횟수가 올바르게 입력이 안될 시 error 처리한다.
- [] error처리를 할때는 무조건 "[ERROR]"이라는 메세지와 함께 `throw new Error()`로 프로그램을 종료한다.
- [] 입력값이 비어 있거나 형식이 다를 경우에도 에러 처리한다.

### 출력

- [] 각 라운드마다 `이름 : ---` 형식으로 현재까지의 진행도를 출력한다.
- [] 각 자동차의 이동 거리는 '-'의 개수로 표현한다.
- [] 모든 경주가 끝나면 최종 우승자와 함께 "최종 우승자 : pobi" 폼으로 최종 결과를 출력한다.
- [] 공동 우승자가 있을 경우, "최종 우승자 : pobi, woni" 폼으로 공동 우승자들 이름들을 쉼표(,)로 구분하여 출력한다.
